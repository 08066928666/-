# AI 翻译输入法 · Web 演示（非最终产品）

> **请安装原生输入法**：[`ai-ime-mobile`](../ai-ime-mobile/README.md)  
> - Android：`ai-ime-android/` → 打包 APK，系统设置里启用  
> - iOS：`ai-ime-ios/` → Xcode 键盘扩展，安装到 iPhone  
>
> 本 Web 目录仅为演示，词库较大可能导致**黑屏或加载慢**，不作为正式方案。

一款**自带翻译功能的普通中文输入法**：日常拼音输入体验对标系统输入法，需要与外国人交流时开启智能模式，自动完成「看懂对方」和「用中文回复」的双向翻译。

## 打开方式

用浏览器打开 `index.html`（需联网加载 CDN）。

首次克隆后若缺少 `dict-words.js`，运行：

```bash
curl -fsSL https://raw.githubusercontent.com/mozillazg/phrase-pinyin-data/master/pinyin.txt -o /tmp/pinyin.txt
node scripts/build-dict.mjs /tmp/pinyin.txt
```

## 输入能力（对标 iOS 拼音）

- **4 万+ 词条**（基于开源词库 mozillazg/phrase-pinyin-data）
- **整词/整句候选**：`nihao`→你好，`xiexie`→谢谢
- **候选栏在键盘上方**（iOS 布局），空格选首词，1-9 数字选候选
- **拼音预编辑区**：未确认拼音蓝色下划线显示
- **123 标点面板**：，。！？等
- **拼 / 中 切换**：内置拼音 vs 系统输入法

## 使用场景

与外国同事、朋友聊天，或在社交 App 里收到外语消息时：

1. **收消息**：识别外语，附上中文对照
2. **发消息**：输入中文，输入法自动译成对方语言，可附带中文对照

## 原型演示

- 左侧：聊天界面模拟（可切换英语 / 日语对方）
- 底部：类 iOS 中文键盘 + **AI 智能模式** 开关
- 智能模式开启时：
  - 对方消息显示「原文 + 中文」
  - 输入中文时实时预览外语译文
  - 发送时自动附带双语内容

## 产品功能

| 模块 | 说明 |
|------|------|
| 普通模式 | 对标系统输入法：拼音、词组、标点 |
| 智能模式 | 语言检测 + 实时双向翻译 |
| 收消息 | 自动检测日/英/韩等，叠加中文对照 |
| 发消息 | 中文输入 → 翻译 → 双语发送（可只发译文） |
| 设置 | 目标语言、是否附带中文 |

## 技术路线

- **iOS**：Keyboard Extension + App Group 共享翻译服务
- **Android**：InputMethodService
- **Windows**：见 `ai-ime-windows/` — 悬浮输入栏 + 剪贴板监听 + 全局热键
- **翻译引擎**：本地小模型（低延迟）+ 云端大模型（高质量）

## 与微信翻译的对比

| | 微信内置翻译 | 本方案 |
|--|-------------|--------|
| 范围 | 仅微信内 | 系统级，全 App 通用 |
| 流程 | 长按 → 翻译 → 手动回复 | 输入即翻译，一键双语发送 |
| 输入 | 需切换翻译功能 | 输入法内置，日常与翻译一体 |
