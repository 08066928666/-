# AI 智能输入法 · 原型

对标苹果系统输入法，核心差异是 **AI 智能模式**：在聊天场景中自动完成「看懂对方」和「用中文回复」的双向翻译，省去「翻译 → 复制 → 粘贴 → 发送」的步骤。

## 打开方式

用浏览器打开 `index.html`（需联网加载 CDN）。

首次克隆后若缺少 `dict-words.js`，运行：

```bash
curl -fsSL https://raw.githubusercontent.com/mozillazg/phrase-pinyin-data/master/pinyin.txt -o /tmp/pinyin.txt
node scripts/build-dict.mjs /tmp/pinyin.txt
```

## 输入能力（对标 iOS 拼音）

- **4 万+ 词条**（基于开源词库 mozillazg/phrase-pinyin-data）
- **整词/整句候选**：`nihao`→你好，`womenyiqiwan`→我们一起玩
- **候选栏在键盘上方**（iOS 布局），空格选首词，1-9 数字选候选
- **拼音预编辑区**：未确认拼音蓝色下划线显示
- **123 标点面板**：，。！？等
- **拼 / 中 切换**：内置拼音 vs 系统输入法

## 使用场景

打游戏时 Steam 上外国人发来问候，你能看懂英文但只会打中文。开启智能模式后：

1. **收消息**：自动识别外语，附上中文对照
2. **发消息**：你输入中文，输入法自动译成对方语言，中英对照一并发出

## 原型演示

- 左侧：Steam 聊天模拟（可切换英语 / 日语对方）
- 底部：类 iOS 中文键盘 + **AI 智能模式** 开关
- 智能模式开启时：
  - 对方消息显示「原文 + 中文」
  - 输入中文时实时预览外语译文
  - 发送时自动附带双语内容

## 产品功能规划

| 模块 | 说明 |
|------|------|
| 普通模式 | 对标苹果输入法：拼音、联想、表情、语音 |
| 智能模式 | 会话级语言检测 + 实时双向翻译 |
| 收消息 | 自动检测日/英/韩等，叠加中文副标题 |
| 发消息 | 中文输入 → AI 翻译 → 双语发送（可只发译文） |
| 设置 | 目标语言、是否附带中文、游戏场景低延迟模式 |

## 技术路线（正式版）

- **iOS**：Keyboard Extension + App Group 共享翻译服务
- **Android**：InputMethodService + 悬浮翻译条
- **Windows（Steam）**：见 `ai-ime-windows/` — 悬浮输入栏 + 剪贴板监听 + 全局热键
- **翻译引擎**：本地小模型（低延迟）+ 云端大模型（高质量），按场景切换

## 与微信翻译的对比

| | 微信内置翻译 | 本方案 |
|--|-------------|--------|
| 范围 | 仅微信内 | 系统级，Steam/Discord 等通用 |
| 流程 | 长按 → 翻译 → 手动回复 | 输入即翻译，一键双语发送 |
| 准确度 | 机器翻译 | AI 上下文理解，可针对游戏术语优化 |
