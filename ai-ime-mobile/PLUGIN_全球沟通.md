# 实时翻译插件 · 产品说明（给产品 / 开发）

## 你要解决什么问题

和外国人聊天时：

- **看懂对方**：对方发外语，你能像看**歌词字幕**一样立刻看到母语译文  
- **回复对方**：你用母语打字，对方收到的是他的语言  
- **不限于微信**：Telegram、LINE、Discord、邮件、游戏聊天都可用  

LINE 的「AI 回信」等主要服务**同语种**用户；我们要做的是**跨语种**无障碍沟通。

---

## 产品形态：不是新输入法，是「翻译插件」

用户心智：

```
安装插件 → 继续用原来的输入法（仓 / 系统 / 搜狗）
         → 多出来：字幕式译文 + 发送时自动翻译
```

技术上通常是 **「键盘扩展 + 小助手 App」** 两件套，而不是在搜狗里装一个 `.apk 插件`（市面输入法大多不开放插件市场）。

```
┌──────────────────────────────────────────────┐
│  歌词式悬浮条 / 键盘顶栏                        │  ← 收：外文 → 你的母语
│  「Hey, are you free?」                       │
│  「嘿，你有空吗？」                             │
├──────────────────────────────────────────────┤
│  发送预览 + 一键双语                            │  ← 发：母语 → 对方语言
├──────────────────────────────────────────────┤
│  原有输入法（用户自选，我们不重做）              │  ← 仓 / 苹果 / 其他
└──────────────────────────────────────────────┘
```

---

## 功能 1：收消息 · 歌词式实时翻译（核心差异）

### 交互（目标体验）

1. 对方发来外文（或你选中一段外文）  
2. 屏幕边缘或键盘上方出现**两行字幕**：  
   - 上行：原文（小字、浅色）  
   - 下行：你的母语（大字、清晰）  
3. 不离开当前 App，不切微信、不长按菜单  

### 实现路径（按现实可行性排序）

| 方式 | 体验 | iPhone | Android | 说明 |
|------|------|--------|---------|------|
| **A. 复制即译** | 复制后 0.5s 内出字幕 | ✅ 推荐 | ✅ 推荐 | 用户多按一下「复制」，最稳、可上架 |
| **B. 选中文本 + 分享/翻译** | 两步 | ✅ | ✅ | 系统菜单扩展 |
| **C. 剪贴板自动监听** | 复制即显，零额外操作 | ⚠️ 需完全访问/后台 | ✅ 较易 | iOS 键盘扩展权限严 |
| **D. 屏幕识别（无障碍/OCR）** | 真「实时」 | ❌ 难上架 | ⚠️ 政策敏感 | 隐私与审核风险大 |

**MVP 建议：先做 A（复制即译 + 歌词悬浮条）**  
习惯后几乎和「实时」一样快；也比硬做屏幕监听更容易过审、全球适用。

> **合规**：剪贴板监听须用户明示开启；禁止无障碍读屏。详见 [COMPLIANCE_合规与隐私.md](COMPLIANCE_合规与隐私.md)。

### 与微信 / LINE 的对比

| | 微信 | LINE | 本插件 |
|--|------|------|--------|
| 看懂对方 | ✅ 长按消息可翻译 | ❌ **聊天里没有类似长按翻译** | ✅ 任意 App |
| AI 回信 | 有（偏同语种） | 有（偏日语母语者） | 跨语种：母语→外文 |
| 操作 | 长按 → 翻译 | 需复制到别的 App 或自己查 | **复制 → 歌词条** |
| 显示 | 气泡内小字 | — | **双行字幕**，键盘上方常驻 |
| 回复 | 自己译或机翻粘贴 | 同上 | **发送时自动翻译** |

**LINE 是重点场景之一**：在日本、台湾、东南亚很常用，和外国人（英/中/韩等）聊天时，官方没有微信那种「长按即译」，用户往往要切出去查词典或翻译 App。插件的价值在这里特别明显。

典型流程（LINE）：

1. 对方发来日语/英语 → 你**复制**这句话  
2. 键盘上方立刻出现歌词条：`原文` + `中文`  
3. 你用仓输入法打中文 → 预览日语/英语 → 发送  

### 母语识别

- 首次安装：选择「我熟悉的语言」（默认简体中文）  
- 自动检测对方语言（英/日/韩/西/法…）→ 译成你的母语  
- 本地缓存最近 N 条对照，方便扫一眼历史

## 功能 2：发消息 · 母语输入，对方收到他的语言

| 能力 | 说明 |
|------|------|
| **边打边预览** | 键盘上方显示：你将发送的外文 |
| **发送翻译** | 点发送/回车 → 插入「外文」或「外文 +（母语）」 |
| **目标语** | 按会话记忆或手动切换（英/日/韩…） |

**Hook 点**：只在「发送/回车」动刀，**不改**底座输入法的拼音与候选。

---

## 功能 3：与 LINE「AI 回信」的差异

| LINE AI 回信 | 本插件 |
|--------------|--------|
| 在对方语言里生成回复建议 | 你用**母语**想说什么，再译成对方语言 |
| 面向同语种润色 | 面向**跨语种**沟通 |
| 绑定 LINE | **任意聊天 App** |

可后续加：根据对方上一句外文，推荐 2～3 条**母语回复建议**（再自动译成外文），那是第二期。

## 平台方案（你是 iPhone 用户）

### 阶段 0 · 现在就能用（零开发）

- 打字：**仓输入法**（App Store）  
- 看懂：**翻译** App 或复制后粘贴  
- 局限：无歌词悬浮、要切换 App  

### 阶段 1 · MVP 插件（最小开发）

**两个安装包（用户感觉像一个产品）：**

1. **「无障碍翻译」助手 App**（设置母语、API、悬浮条权限）  
2. **键盘扩展**（或基于仓输入法 fork 一小条工具栏）  

**收消息**：复制外文 → 助手 App / 键盘顶栏 **歌词式两行**  
**发消息**：键盘顶栏预览 + 发送时翻译  

iOS 限制：键盘**读不到**别的 App 聊天框里的字，所以「收」必须依赖 **复制** 或 **选中+扩展**；这是苹果规则，不是设计偷懒。

### 阶段 2 · 体验增强

- 剪贴板监听（复制即译，少一步）  
- 会话记忆：这个聊天默认译成英语  
- 常用句、礼貌用语模板（游戏/商务/日常）  

### 阶段 3 · 翻译质量

- 接入 DeepL / Google / GPT（需联网与隐私说明）  
- 游戏/网络用语微调

## Android 路线（更易做「歌词悬浮」）

底座推荐：**语燕输入法** + 本仓库 `ai-ime-yuyan/addon/`  

- 可有 **悬浮窗权限** → 真·歌词条浮在屏幕底部  
- 剪贴板监听更宽松  
- 发送 Hook 已在 `SmartTranslate.kt` 有雏形  

---

## 给外包开发的任务边界（一页纸）

**做：**

- 助手 App：母语设置、翻译 API、歌词 UI 组件  
- 剪贴板/复制监听 → 调用翻译 → 显示双行字幕  
- 键盘扩展：发送前 `translateOutgoing`，发送时 `bilingualSend`  
- 不修改 Rime/拼音/词库  

**不做：**

- 新输入法、新词库、九宫格 UI  

**交付物：**

- iOS：TestFlight 安装包（助手 + 键盘）  
- Android：APK（语燕定制版 或 独立键盘+悬浮）  

**参考代码：** 本仓库 `Translator.swift`、`SmartTranslate.kt`、`PRODUCT_加装翻译.md`
