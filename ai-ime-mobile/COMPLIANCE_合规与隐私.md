# 合规与隐私 · 产品设计红线

本文档约束 **AI 翻译输入法 / 助手** 的功能边界，避免审核被拒、隐私投诉或违反聊天平台规则。  
**开发、外包、上架前必读。**

---

## 一、我们明确不做的事（红线）

| 能力 | 为何不做 |
|------|----------|
| **读屏 / 无障碍自动读聊天** | Apple/Google 审核敏感；易被认定侵犯他人隐私；中国《个人信息保护法》等对「未经同意收集他人信息」要求严 |
| **后台静默扫描 LINE/微信私聊** | 违反平台规则；技术上 iOS 也不允许第三方读 1:1 聊天内容 |
| **上传完整聊天记录做训练** | 无合法依据；用户未授权 |
| **默认开启剪贴板监听** | 剪贴板可能含密码、验证码、银行卡号；须 **用户明示同意** 后才监听 |
| **默认开启云端翻译** | 用户文本会出境或经第三方 API；须说明数据去向并取得同意 |

> **产品口号对应合规版：**  
> 「复制即懂」= 用户 **主动复制** 后才译，不是偷读。  
> 「发送即译」= 只处理用户 **自己输入** 的内容。

---

## 二、推荐实现路径（与法规对齐）

| 功能 | 合规做法 | 当前代码 |
|------|----------|----------|
| 收消息 · 歌词条 | 用户复制 → 本地/云端翻译 → 仅显示字幕，**不写入对方聊天记录** | `ClipboardMonitor` / `LyricSubtitleBar` |
| 发消息 · 发送翻译 | 仅读当前输入框内用户草稿；发送前可预览 | `handleSend` / `translateAndSendLine` |
| 剪贴板 | **默认关**；设置里开关 + 说明「仅在你复制后读取一次」 | `SharedSettings.clipboardMonitoringEnabled` |
| 联网翻译 | **默认关**或首次弹窗同意；隐私政策列明 API 服务商 | `cloudTranslationEnabled` |
| 演示词典 | 纯本地、不上传，可作为默认模式过审 | `Translator` / `SmartTranslate` demo |

**不做 D 路径（屏幕 OCR / 无障碍）**，见 `PLUGIN_全球沟通.md` 实现路径表。

## 三、iOS 专项（App Store）

### 3.1 键盘「允许完全访问」

苹果要求：开启 Full Access 的键盘扩展必须在 App 内 **清楚说明用途**。

| 用途 | 是否必须 Full Access |
|------|---------------------|
| 本地拼音 + 演示词典翻译 | 否 |
| 读取剪贴板显示歌词条 | **是** |
| 调用云端翻译 API | **是**（需网络） |

**文案建议（设置页）：**

> 开启「允许完全访问」后，键盘可在您 **复制外文消息后** 显示翻译字幕，并在您同意后将 **您输入的文字** 发送至翻译服务。我们不会读取您未复制或未输入的内容。

### 3.2 审核材料

- App Privacy 标签：若接云端 API，勾选「用户内容」用于 App 功能  
- 提供可访问的 **隐私政策 URL**（中英至少一种）  
- 演示账号 / 审核说明：强调「复制触发」，非自动读屏  

### 3.3 剪贴板（iOS 16+）

系统会提示 App 读取剪贴板。应：

- 仅在用户打开「复制即译」后监听  
- 不长期缓存剪贴板历史  
- 密码、验证码类内容：检测到纯数字短串时可 **不翻译、不展示**（可选增强）

## 四、Android 专项（Google Play / 国内商店）

| 权限 | 合规用法 |
|------|----------|
| 输入法服务 | 仅处理焦点输入框文本，不越权读其他 App |
| 剪贴板监听 | 用户同意 + 前台输入法或助手 App 活跃时 |
| 悬浮窗 | 若做全局歌词条，须单独说明用途；Play 对 overlay 审核趋严，优先键盘顶栏 |
| 无障碍服务 | **禁止**用于读聊天；若误用会导致下架 |

语燕底座为 **GPL-3.0**：分发 APK 须遵守开源义务（见 `ROADMAP.md`）。

## 五、数据与跨境（PIPL / GDPR）

接入 DeepL、Google、OpenAI 等时：

1. **隐私政策**写明：处理目的、第三方名称、是否出境、保留多久  
2. **最小必要**：只发送待译字符串，不带联系人、设备 ID（除非统计且匿名）  
3. **用户同意**：设置内「使用云端翻译」开关，默认关或首次必选  
4. **撤回与删除**：提供关闭云端、清除本地缓存（歌词条历史）  
5. **欧盟用户**：GDPR 合法依据一般为「同意」；提供数据导出/删除入口  

演示版使用 **本地词典** 时，可在隐私政策中写「默认不上传任何内容」。

## 六、聊天平台（LINE / 微信 / Telegram）

| 规则 | 我们的边界 |
|------|------------|
| 不得未授权抓取他人消息 | 仅用户 **复制** 的单条文本 |
| Bot 不得冒充用户自动回复私聊 | 不做自动发送 Bot；用户手动点发送 |
| 第三方插件不得破解客户端 | 不注入 LINE/微信客户端，只做系统输入法层 |

## 七、上架前检查清单

- [ ] 隐私政策页面（网页或 App 内）  
- [ ] 首次启动隐私同意（可拒绝，仍可用本地演示）  
- [ ] 剪贴板监听 **默认关闭**，设置里带说明  
- [ ] 云端翻译 **单独同意**  
- [ ] 无无障碍读屏、无 OCR 扫聊天  
- [ ] App Store / Play 隐私问卷与实现一致  
- [ ] 日志不打全文聊天内容

## 八、代码中的开关（本仓库）

| 平台 | 偏好键 | 默认 |
|------|--------|------|
| iOS | `SharedSettings.clipboardMonitoringEnabled` | `false` |
| iOS | `SharedSettings.cloudTranslationEnabled` | `false` |
| iOS | `SharedSettings.privacyConsentAccepted` | `false` |
| Android | `SmartTranslatePrefs.clipboardMonitoringEnabled` | `false` |
| Android | `SmartTranslatePrefs.cloudTranslationEnabled` | `false` |

正式接 API 时：仅当 `cloudTranslationEnabled == true` 才调用网络。

---

## 九、给用户的一句话

> 你的聊天内容 **只有在你复制或自己打字时** 才会被翻译；我们不会自动读取 LINE 或微信里的对话。云端翻译可在设置中随时关闭。
