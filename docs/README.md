# 固定アクセス URL（GitHub Pages）

このデモは **GitHub Pages** でホストされ、一時的なトンネルリンクと異なり **安定してアクセス** できます。

## デモを開く

**https://08066928666.github.io/-/**

（リポジトリ名が `-` のため URL がこの形式になります）

## ローカルで開く（ネット不要）

プロジェクト内のファイルをダブルクリック：

- `TokubaiHub-デモ.html`
- `tokubai-hub/demo-standalone.html`

## フル版アプリ（自分の PC）

```bash
cd tokubai-hub
npm run demo
```

ブラウザで http://localhost:3000
